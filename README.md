Final Instruction

Do not build a generic e-commerce template. Build a world-class digital luxury experience that could compete with Cartier, Tiffany & Co., and Bulgari. Every page should feel like a premium boutique, every animation should be purposeful, and every interaction should reinforce exclusivity and craftsmanship.

The AI Virtual Try-On must be the centerpiece of the experience, using MediaPipe, Three.js, React Three Fiber, and physically based rendering to keep jewellery accurately aligned with the user's face, neck, hands, or body in real time with realistic lighting, depth, and motion. The result should be fast, immersive, photorealistic, and polished enough to impress both luxury customers and professional jewellers.
